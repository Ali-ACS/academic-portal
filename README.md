# 🎓 Academic Portal

An interactive academic portal designed to streamline study material organization, track academic tasks, and provide quick access to essential student tools and links.

---

## ✨ Features
* **Responsive Design:** Fully compatible with desktop, tablet, and mobile screens.
* **Dual Theme Support:** Clean light and dark mode styling for comfortable viewing.
* **Interactive Interface:** Easy-to-navigate sections for academic schedules and resources.

---

## 🛠️ Technologies Used
* **HTML5** – Page structure and semantic layout
* **Tailwind CSS** – Styling and responsive design framework
* **JavaScript** – Dynamic UI behavior and interactivity
